## 3. 机制（最小复现，只用到 WORK-02 零改动文件）

`backtest_store.py:41` 在**模块导入期**读取环境变量：

```python
RUNS_ROOT = Path(os.environ.get(
    "OI_RESONANCE_RUNS_DIR", str(PROJECT_ROOT / "回测日志" / "oi_resonance_v1" / "runs")))
```

`test_backtest_store.py:22-25` 假定「设了环境变量再 import 就能生效」：

```python
TMP = Path(os.environ.get("OI_RESONANCE_RUNS_DIR", "/tmp/bt_store_test"))
os.environ["OI_RESONANCE_RUNS_DIR"] = str(TMP)
S = importlib.import_module("backtest_store")     # ← 若已缓存，返回旧对象，env 设置被忽略
```

`test_oi_resonance_v1_backend_p0p1.py:31` 在**模块级**先一步导入它（此时未设 env）：

```python
import backtest_store as S        # noqa: E402
```

最小复现（**不含任何 WORK-02 模块**）：

```python
import os, sys, importlib
sys.path.insert(0, "框架/backend")
import backtest_store                       # 模拟 p0p1.py:31，无 env
print("第1次 RUNS_ROOT =", backtest_store.RUNS_ROOT)
os.environ["OI_RESONANCE_RUNS_DIR"] = "/tmp/bt_store_test"
m = importlib.import_module("backtest_store")  # 模拟 test_backtest_store.py:25
print("第2次 RUNS_ROOT =", m.RUNS_ROOT, " 同一对象 =", m is backtest_store)
```

实测输出：

```
第1次 RUNS_ROOT = /Users/boos/Desktop/威科夫因子共振趋势/回测日志/oi_resonance_v1/runs
第2次 RUNS_ROOT = /Users/boos/Desktop/威科夫因子共振趋势/回测日志/oi_resonance_v1/runs

⇒ 环境变量只在**首次**导入时被读取；测试第 2 次的赋值完全无效。
`RUNS_ROOT` 停在项目默认目录，而 `TMP` 是 `/tmp/bt_store_test`，两者不一致 ⇒ 两条断言必然失败。

## 5. 附带损害：测试产物误落**生产** runs 根

```

  ├── bt_20261016T081659Z_ffffffff      387 B
