## 1. `SignalListPanel.tsx`

### 1.1 删除 `DEMO_ARKM_SIGNAL` 演示信号与「缺 ARKM 就插入」逻辑

**before**（`currentSignals` memo）：
```tsx
const currentSignals = useMemo(() => {
  const list = signals.filter(isCurrentSignal);
  const hasArkm = list.some((s) => (s.tokenSymbol||'').toUpperCase()==='ARKM' || ...);
  if (!hasArkm) { return [DEMO_ARKM_SIGNAL, ...list]; }   // ← 演示卡插入正式列表
  return list;
}, [signals]);
```
**after**：
```tsx
const currentSignals = useMemo(() => signals.filter(isCurrentSignal), [signals]);
```
同时**整块删除** `DEMO_ARKM_SIGNAL` 常量（含固定入场 1.425、目标 1.575、OI增24%、巨鲸均价 1.40 等虚构字段）。

### 1.2 `resolveSignalPrices`：删除硬编码与推导价格，并纠正「现价冒充入场价」

**before**：ARKM 硬编码 `1.425 / 1.420 / 1.350 / 1.575`；其余币种缺价时用
`trigger*1.003`、`entry±5%`、`entry+1.5R` 推导；并把 `signal.currentPrice` 填入「入场价」列。
**after**：只取信号自带真实字段，缺失即 `null`（页面显示 `—`）；
返回值字段 `entryPrice` → **`currentPrice`**，列标题「入场价」→ **「现价」**。
成交/入场价**不在此展示**（只由服务端账本 fill 产生）。

### 1.3 `resolveReason`：删除编造理由

**before**：缺理由时拼出
`大户持仓做多(1.62)背离散户(0.81) · OI增24% · 现价贴近巨鲸均价(1.40) · 插针收回`
（其中 1.62/0.81/24%/1.40 均为**常量兜底**）；ARKM 有专用分支。
**after**：只**原样透出**后端结构化证据（`actionableReason`/`validityReason`）；
缺失 ⇒ `null`，页面显示「—（无结构化理由，缺失即未知）」。

### 1.4 空态与底部状态

空态补充说明「不使用任何演示/兜底样本」+「模拟盘尚未通过闭环验收，服务端已阻断全部新开仓
（退出/费用/资金费照常处理）」。

## 2. `InlineExpandedChart.tsx`

**before**：
```tsx
const isBtc = token.symbol === 'BTC';
const trigger = activeSignal?.triggerPrice ?? (isBtc ? 67150 : null);
const entry   = activeSignal?.currentPrice ?? (isBtc ? 67200 : null);   // ← 现价当入场价
const stopLoss= activeSignal?.stopLossPrice ?? (isBtc ? 66400 : null);
const target  = activeSignal?.targetPrice ?? (isBtc ? 69000 : null);
... title: `入场价 ${entry...}`
```
**after**：删除全部 BTC 兜底价；`entry` → `current`，线标题「入场价」→「现价」；
只用信号自带字段，缺失则不画线。依赖数组 `[token.symbol, activeSignal]` → `[activeSignal]`。
