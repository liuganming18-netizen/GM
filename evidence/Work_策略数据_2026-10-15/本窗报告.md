## 2. 数据来源与核验（四类来源）

| 来源 | 用途 | 核验要点 |
|---|---|---|
| 热库 `market_v2.sqlite3` | K 线近期尾段、资金费、OI | `mode=ro`+`query_only`；`candles` 视图按 `open_time` 去重并入 |
| 冷档 `archive/parquet/` | K 线全历史、funding、oi 分片 | 逐币逐年 `candles/ funding/ oi/ sources/` |
| 补件 `Work_补缺_2026-10-14/` | K 线补件、资金费 11,773、OI 13,776 | 按 `(symbol,time)` 并入，仅补未存在的键 |
| 原件 `raw_oi_metrics/`、`raw/mark1h/`、`raw/funding/` | OI+四比率（同源）、结算 mark、费率校验 | 官方日包/月包直接解析 |

**关键核验结论**

1. **OI 与 4 个比率同源同事件**：`raw_oi_metrics/{symbol}/*.zip`（官方 metrics 日包）单行同时含 `sum_open_interest`、`sum_open_interest_value`、`count_long_short_ratio`、`sum_toptrader_long_short_ratio`、`count_toptrader_long_short_ratio`、`sum_taker_long_short_vol_ratio`。因此 OI 数量/金额与各比率天然同刻同事件，无需跨源拼接。
2. **桶口径**：metrics `create_time` = **5m 桶起点**（00:00–23:55，288 槽/日）；实测与热库 `oi_history.ts` **同刻同值**（BTCUSDT 2026-10-07T00:00 → 95689.517 双方一致）。抽样 14 币各 7,488 个共同时点**全部一致**。
3. **旧年份重复行**：早期日包（如 2020-09-01）每行**整行重复**一次 → 按 `ts` 去重保留首个。
4. **K 线**：冷档全历史 + 热库补尾段，按 `open_time` 去重；1h/4h/15m 桶起点网格 **0 偏移**；主键唯一、**0 重复**。
5. **资金费**：结算时刻为 **8h 网格**（00:00/08:00/16:00 UTC），毫秒抖动 ≤4ms（原值保留，不移时）；冷档费率 vs 官方归档 **0 冲突**。
6. **结算 mark**：冷档 funding 归档**不含 mark**；按结算时刻从 `raw/mark1h/` 官方归档取 `mark_open`（1h 桶起始 mark），再由官方 API `fundingRate.markPrice` 补 ≥2024 的缺口。**非当前收盘价替代**。

## 5. 已补采 / 仍缺 / 可用于回测范围

### 已解析（复用，无需重下）
- K 线全历史：冷档 parquet 直接解析 + 热库尾段 + 补件并入
- 资金费：冷档 + 热库 + 补件 11,773 条

### 本轮定向补采（仅缺才补，不重下全池）
- **结算 mark**：`raw/mark1h` 归档补 **2,101,247** 条 → 官方 API `fundingRate` 定向补 **7,663** 条；热库/归档原已有 mark **79,107** 条
- 未调用任何全池下载；未新增 5m K 线全池历史

### 仍缺（官方不可得，已列 blocking_items）
1. **结算 mark 1,838 条 / 2,189,855 = 0.084%**（124 币）：
   - `mark1h` 官方月包空洞（如 BTCUSDT 2021-07-01 整天，06 包止于 06-30 23:00、07 包起于 07-02）
   - 5 个中文名符号（哈基米/币安人生/我踏马来了/牛来/龙虾 USDT）**无 mark1h 归档**
   - 官方 API `fundingRate.markPrice` 仅 ≥2024 有值，**<2024 返回空串** ⇒ 旧空洞不可恢复
   - 影响：这些 `(symbol, funding_time)` 的正式资金费记账按合同应列**不通过**或阻断该持仓正式结果
2. **mark1h 数据集缺 5 个符号**（同上 5 币）
3. **合约停牌空洞**（K 线）：官方已证无事件（前一/后一日 96 根、当日自某时点起，逐笔成交 0 笔）——**不补，回测需显式处理空洞**
4. **OI 源包无事件段**：M4 OI 因子须按币分别核算可用窗口，不得用全市场平均覆盖代替

### 可用于回测范围
