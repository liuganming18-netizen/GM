## 3. 接口口径统一（已改）

每个响应现在都能回答「哪个策略版本 / 哪套规则 / 哪个账本 / 哪份数据」：

- **运行身份** `_runtime_identity()`：`strategy_version`、`rule_version`（冻结 `F_WX_v2.2_project_closure_user_5000_shared`）、`param_hash` + `param_hash_basis`、`params_source`、`rule_view_available`、`data_version`、`daily_list_version`、`pool_rule_identity`
- **账本来源** `ledger_source`：纸面=四臂路径/存在性/SHA/行数/身份（`kind=paper_ledger`）；历史回测=`searched_dirs`+`found`（`kind=backtest_ledger`）；信号=`live_signals.sqlite3`（`kind=live_signal_db`）；实盘=`kind=exchange_readonly`
- **信号/实盘端点也带身份**：`/api/v1/signals` 的合并层（`adapter._v1_signals_merged`）此前只搬 `items/total/has_more/quality`，把实时层身份整块丢掉；现改为**透传**，`signals`/`accounts` 同样能追溯规则版本与数据版本
- **真实健康** `live_health()`：心跳 TTL **绑定** worker 调度间隔（`LIVE_WORKER_INTERVAL_SEC`，默认 900s），
  缺失/过期 ⇒ `down`/`stale`；**不因「进程在」或「返回 200」报 ok**；市场采集进程与策略 worker 分开；
  账本缺失 ⇒ `degraded`。**停止的 worker 不再显示健康**（实测心跳停 5h+ ⇒ `down`）。
- **缺失态**：纸面/复盘缺库 ⇒ `quality.status="unavailable"`；历史回测缺账本 ⇒ `"missing"`；
  订单/资金费/开平仓也补齐了 fail-closed（原来会直接抛 500）
- **审计补全**：`legacy_audit()` 汇总旁表（`legacy_position_audit` 25 行 / `legacy_signal_audit` 2 行，
  按 `verification_status` 分组）+ 审计 JSON + 因果审计 + 旧账本存续状态

## 4. 复盘指标口径修正（已改）

| 指标 | 旧口径（错） | 新口径 |
|---|---|---|
| 初始权益 | 硬编码 `len(arms)×5000` | 各臂**真实账本** `initial_equity` 之和 |
| 曲线推进 | 各臂兜底硬编码 5000 | 各臂按真实初始权益起步、逐时点同步推进 |
| **夏普** | 剔除零收益日（`abs(Δ)>1e-8`）再 `sqrt(365)` ⇒ **系统性抬高** | **完整等间隔 UTC 逐日**净值收益，**保留平盘日**；样本不足/零波动 ⇒ `None` |
| **月度收益** | 按**平仓时间**归集 ÷ 初始权益（现金流归集，不是月收益） | **账户月界净值**：`本月末净值 / 上月末净值 − 1`；首月无基准则标缺；另附 `realized_pnl_by_close_month` 作**补充事实** |
| **ALL 组合盈亏比** | 各臂 `profit_factor`/`win_loss_ratio` **算术平均** | **合并明细**：Σ盈利/Σ亏损、平均盈利/平均亏损 |
| **ALL 组合回撤** | 各臂回撤**最大值** | **同步组合净值**峰谷回撤 |
| **BTC 基准** | 1h 收盘标在 `open_time` 且 `bisect<0` 时**强取首条**（前视） | 可用时刻 = `open_time+1h`；起点前无可用价 ⇒ **该段不给基准**（`None`），前端不绘线 |
| 无定义值 | 一律 `0.0`（冒充「已测得的 0」） | `None`（缺失态），前端显示 `—` |
| 身份注入 | 复盘响应不带身份 | 注入 `**ident` + `ledger_source` + `metric_basis`（口径自述） |

另修复一处**崩溃**：`_align_btc_benchmark` 改为返回 `(map, meta)` 后，调用处仍按单值用 ⇒ 已改为解包。

`monthly_returns` 保持前端消费的三个键（`pnl`/`pnl_usd`/`count`），另加 `basis`、`month_end_equity`、
`realized_pnl_by_close_month`。

**前端最小必要同步**（仅 3 处、无结构改动；不做会直接崩或撒谎）：
1. `BacktestReviewView.tsx` 热力图：原判 `val !== undefined`，而新口径首月返回 `null`
   ⇒ `null.toFixed(1)` 会**抛错**；改为同时判 `null`，并让 YTD 跳过缺失月；
2. 同上脚注与 tooltip：原写「月度% = 该月已平仓净盈亏 / 初始权益」已与新口径不符 ⇒ 改为月界净值口径；
3. `api/types.ts`：`monthly_returns` / `RawBacktestSummary` / `RawArmComparison` 的派生指标标注 `| null`。

`npx tsc --noEmit` 通过（0 error）。前端进程未重启（Vite HMR 自动生效），页面仍 200。
