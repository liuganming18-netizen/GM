## 三、逐字段映射 / 单位 / 语义

详见 `验收证据/聪明钱/币安聪明钱_字段映射与语义_2026-10-07.md`。要点：

| 项 | 字段 | 单位 | 口径 |
| --- | --- | --- | --- |
| 持仓金额 | `long/short.positions_usd` | **USDT** | 按**当前标记价**折算的持仓市值（`Qty × markPrice`，**非**开仓成本额） |
| 数量 | `long/short.qty` | **标的币** | 与金额**分列**，绝不写入金额槽（有单测守护） |
| 内部占比 | `whale_share_percent` | % | 分子=该侧鲸鱼仓位；**分母显式给出**（该侧总持仓额） |
| 多空比 | `ratios.long_short_ratio` | 倍 | **数量比** `longQty/shortQty`（实测 10.174 = 30,297,307/2,977,813）；**不是人数比**（173/94=1.84） |
| 持仓均价 | `avg_entry_price` | `USDT/标的币` | 该侧交易员平均开仓价；**加权方式币安未公开**（如实标注） |
| 标的身份 | `symbol` / `market_id` | — | 币安 USD-M 合约标识 |
| 更新时间 | `update_time_ms` | ms | **日级队列标记**（ARX 与 BTC 完全相同，不随分钟推进） |
| 新鲜度 | `last_trade_time_ms` | ms | 来自 `details/list` 聚合行；**真实新鲜度**，`updateTime` **不作为**新鲜度 |

**语义边界（不得冒充）**：这是币安**自定义口径的"聪明钱"队列聚合持仓**，
**不是全市场持仓、不是 OI、不是大户/账户数多空比、不是 taker 买卖量比**。
队列成员判定规则**币安未公开**（`cohort_definition:"undisclosed"`）；
"鲸鱼=保证金 Top 20%"是**社区口径、币安未确认**（`whale_definition:"community_claim_unverified"`）；
`details` 中 `userType=0` 的具名交易员行是**样本个体**，不代表全市场。

## 六、失败 / 陈旧 / 缺字段处理

| 情形 | 行为 |
| --- | --- |
| 上游业务码非成功（如 `000002`） | 网关判失败、**不写有效缓存**；模块回 `available:false` + 具体码与 message |
| 来源被拒绝/封禁（403/418） | 网关置 `blocked`，模块如实回 `RejectedRequest` 原因，**不重试循环** |
| 429 / 限频 | 网关按 `Retry-After` 冷却；模块按网关给出的最早重试时间等待（有界），**不绕过** |
| 本地预算/间隔保护 | `DeferredRequest`，计入 `requests.deferred`，如实上报 |
| 合约无聪明钱覆盖 | `data:null` ⇒ `available:false` + 原因"该合约无聪明钱覆盖"，**不填 0** |
| 非币安标的（OKX） | `available:false` + "只覆盖币安 USD-M"，**不替代** |
| 分母缺失或为 0 | 占比回 **`null`** + `null_reasons` 具体原因，**不填 0** |
| 只有 `*Qty` 没有 `*Positions` | 金额回 **`null`**（数量绝不冒充金额） |
| 快照过期 | `quality.status = stale`，note 写明数据时点、年龄与阈值；**不隐藏** |
| 全池模式扫一轮 ~19 分钟 | 索引标 `full_pool` 时阈值放宽至 1800s（否则误判过期）；有界模式仍 600s |
| 采集失败 | **不覆盖**上一份好快照（失败不静默写成空值） |

### 未完成 / 剩余（**明确列出**）
1. **3 个合约币安确无聪明钱覆盖**：`1000000BOBUSDT`、`PROMPTUSDT`、`PUMPBTCUSDT`

3. **`timeRange` 仅 `ALL/7D/3D/30D/90D` 可用**；页面口径为 `ALL`，本模块默认 `ALL`。
   其余取值币安返回参数非法，**未做**其它窗口。
4. **`updateTime` 语义未获官方文档确认**（实测为日级共享标记）；本模块按实测标注并**不**用于新鲜度。
5. **队列成员判定规则、鲸鱼门槛、均价加权方式** 币安**未公开** ⇒ 只做如实标注，**不推断**。
6. **前端展示未改**：按分工由前端任务接线；本任务只保证 API 侧契约可被其现有代码读取（已 8/8 验证）。
7. **快照为"当前值"非历史序列**：本轮只落当前快照，**未**建时序留存（用户未要求；如需时序需另行定义）。
8. **全池模式下先扫到的标的会随时间变旧**（一轮 ~19 分钟）；默认运行是**有界集合**（页首 48 ∪ 主流 12，
   ~3 分钟一轮，全部新鲜）。

### 已知限制
* 该 bapi 为币安**网页端内部接口、无官方文档**（URL 由公开页面 XHR 与社区逆向共同确认）；
  若币安调整路径/字段，需重新取证。本模块对未知字段**原样透传**、对缺失字段**如实置 null**，故字段增减不会造数。
