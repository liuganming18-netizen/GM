## 1. 真实接口（三个，实测捕获，非猜测）

主机 `www.binance.bh`；前缀 `/bapi/futures/v1/public/future/smart-money/signal`。
**路径含 `/public/`；无 cookie / 无 Authorization / 无验证码即 200**（`credentials:'omit'` + curl 双重验证）。

| 端点 | 关键请求参数 | 作用 |
| --- | --- | --- |
| `/overview` | `symbol`（`timeRange` 可省） | 17 字段总览：人数/数量/**均价**/鲸鱼/浮盈数/`updateTime` |
| `/details/stats` | `symbol` **+ `timeRange` 必填** | 逐侧**当前持仓额(USDT)** + 数量 + 鲸鱼仓位 |
| `/details/list` | `symbol`+`timeRange`+`page`+`rows`+`sortingField`+`sortingOrder` | 明细行：聚合行(`userType=2`) + 具名交易员行(`userType=0`，含 `traderName`/`topTraderId`/`lastTradeTime`) |
| `/list`（兼容别名） | `symbol`+`timeRange`(+`side`/`sortBy`/`page`，实测**被忽略**) | 同族聚合行（保留以便与早期口径对账） |

**参数域实测**（详见 `聪明钱/endpoint_matrix_2026-10-07.json`）：

- `timeRange` 取值域 = `ALL / 7D / 3D / 30D / 90D`；`1H/4H/12H/1D/14D/1W/1M` ⇒ `code=000002 参数异常`。
- `details/*` **缺 `timeRange`** ⇒ `code=000002`（故登记为 `required`）。
- 未覆盖合约（如 `ZZZNOTREAL999`）⇒ `code=000000` + `data:null`（**不是错误**，是"无覆盖"）。
- `side=BUY/SELL/BOTH` 对 `/list` **不构成过滤**（返回同一聚合行）；响应里的 `side` 是**派生方向标签**。

**为什么用 `www.binance.bh` 而不是 `www.binance.com`**：本机实测 `www.binance.com` 该 bapi
直连 **HTTP 000（不可达）**；`www.binance.bh` **200**，且与用户给定页面同源。两者同属币安官方域族。

## 2. 逐字段映射（值 / 单位 / 口径 / 来源）

### 2.1 持仓金额及币种

| 字段 | 单位 | 口径 | 来源 |
| --- | --- | --- | --- |
| `long.positions_usd` | **USDT** | 多头**当前持仓市值** = `longQty × 当前标记价` | `details/stats.longPositions` |
| `short.positions_usd` | **USDT** | 空头同上 | `details/stats.shortPositions` |
| `totals.positions_usd` | USDT | 多空之和 | 二者相加 |
| `totals.total_positions_usd` | USDT | 队列总持仓额 | `overview.totalPositions` |

**口径实测核验**（ARXUSDT，2026-10-07T19:28:32Z）：

```
longQty 30,297,307 × markPrice 0.26904770 ≈ 8,151,5xx   （同刻 longPositions = 8,137,856.66）
```
数量×标记价与 `*Positions` 同量级且随标记价漂移 ⇒ 判定为**按标记价折算的持仓市值**，
**不是开仓成本额**（成本口径只有 `*AvgEntryPrice`）。已在 `positions_basis` 如实标注。

> ⚠️ **`*Qty` 绝不写入金额槽**。`qty` 单位是**标的币**（ARX/BTC…），与 `positions_usd` 分列，
> 并有单测 `test_qty_never_written_into_amount` 守住。

### 2.2 内部占比及分母（分母显式给出，不猜）

| 字段 | 分子 | 分母 | 口径 |
| --- | --- | --- | --- |
| `long.whale_share_percent` | `details/stats.longWhalePositions` | `details/stats.longPositions` | 巨鲸持仓额 / 该侧总持仓额 × 100 |
| `long.whale_traders_share_percent` | `details/stats.longWhales` | `details/stats.longTraders` | 巨鲸**人数**占比 |
| `long.profit_traders_share_percent` | `overview.longProfitTraders` | `overview.longTraders` | 浮盈交易员占比 |
| `long.profit_whales_share_percent` | `overview.longProfitWhales` | `overview.longWhales` | 浮盈巨鲸占比 |

分母缺失或为 0 ⇒ **`null`**（不显示、不填 0），并有单测覆盖。

**币安 `longShortRatio` 的真实口径 = 数量比，不是人数比**（重要纠正）：

```
字段值 10.1743  ← longTradersQty/shortTradersQty = 30,297,307/2,977,813 = 10.174  ✅
人数比            ← longTraders/shortTraders     = 173/94           = 1.84    ❌ 不匹配
```
故 `ratios.long_short_ratio.basis = "qty"`，并显式给出 `numerator` / `denominator`；
另**自行命名**一个人数比 `ratios.traders_long_short_ratio`（**不同口径，不混用**）。

### 2.3 持仓均价及计算口径/时间

| 字段 | 单位 | 来源 |
| --- | --- | --- |
| `long.avg_entry_price` | `USDT/标的币` | `overview.longTradersAvgEntryPrice` |
| `long.whale_avg_entry_price` | 同上 | `overview.longWhalesAvgEntryPrice` |
| `short.avg_entry_price` / `short.whale_avg_entry_price` | 同上 | `overview.short*AvgEntryPrice` |

**口径边界**：这是该侧**交易员（含鲸鱼）的平均开仓价**；币安**未公开加权方式**
（简单平均 / 数量加权未知）⇒ `avg_entry_price_basis` 如实标"未公开"。
时间维度上，均价字段随上游刷新推进；但**不能**用 `lastTradeTime` 反推上游快照时点（见 §2.4）。

### 2.4 时间：三种必须分开（2026-10-08 更正）

| 概念 | 字段 | 含义 | 能否当新鲜度 |
| --- | --- | --- | --- |
| 交易活动时间 | `trade_event_time_ms`（源 `details/list[].lastTradeTime`） | 该队列**最近成交/持仓变动**时点，**只说明活跃度** | ❌ 不能 |
| 上游数据快照时点 | `upstream_snapshot_time_ms` | 币安**未公开** ⇒ 恒 `null`（**不推断**） | ❌ 无 |
| 本机取回/落盘时点 | `local_fetched_at_ms` / `snapshot_refreshed_at_ms` | 本机取回 / 快照落盘时刻 | ✅ **陈旧判据只用它** |
| （参考）日级队列标记 | `update_time_ms`（`overview.updateTime`） | 全标的共享、不随分钟推进 | ❌ 不能 |

- **陈旧（`stale`）判据 = 本机取回时点距今 > `stale_after_s`**（默认 600s = 采集周期 300s × 2）。
  ⇒ 采集停摆 ⇒ 本机取回时点不再推进 ⇒ 判 `stale`；
  **交易活动少（`lastTradeTime` 旧）但本机刚成功取回 ⇒ 判 `ok`**（不误判）。
  单测：`FreshnessTest.test_low_activity_but_freshly_fetched_is_not_stale`。
- 阈值**固定**，**不随 `full_pool` / 扫描用时放宽**（已删除旧的 1800s 放宽；
  单测 `test_stale_threshold_is_never_relaxed_by_full_pool` 守住）。
- 采集器**推进信号**单列：`snapshot.collector`（最近一轮索引 `updated_at` 的年龄），
  用于区分「采集停摆」与「该标的未被本轮覆盖」。

### 2.5 标的身份

`symbol` / `market_id` = 币安 USD-M 合约标识（如 `ARXUSDT`）。**仅币安**：
OKX 行返回 `available:false` + 明确原因，**不以任何其它指标替代**。

## 3. 语义边界（不得冒充，硬约束）

1. 这是币安**自定义口径的"聪明钱/Smart Signal"交易员队列**的**聚合持仓**：
   **不是全市场持仓**、**不是 OI**、**不是**大户多空比 / 账户数多空比 / taker 买卖量比。
   已在 `not_a_substitute_for` 列出。
2. **队列成员判定规则币安未公开** ⇒ `cohort_definition:"undisclosed"`。
3. **鲸鱼门槛**：社区实现称"保证金余额 Top 20%"，**币安未确认** ⇒
   `whale_definition:"community_claim_unverified"`。
4. `details` 中 `userType=0` 的具名交易员行是**样本个体**（`traderName`/`topTraderId`），
   **不代表全市场**；`details_split` 明确区分聚合行与具名行。
5. 缺失一律 `null` + `null_reasons` 具体原因；**不填 0、不用其它指标顶替**。

### 3.1 实测推断 vs 官方确认（**必须逐条区分**，2026-10-08 补）

| 结论 | 性质 | 依据 |
| --- | --- | --- |
| `*Positions` = 按**当前标记价**折算的持仓市值(USDT) = `*Qty × markPrice` | **实测推断** | 本机实测 ARXUSDT `30325969 × 0.26904770 = 8,159,557` ≈ `longPositions` `8,159,781`（差 <0.01%） |
| `longShortRatio` = **数量比**（`longQty/shortQty`），**非**人数比 | **实测推断** | 实测 `30,297,307/2,977,813 = 10.174` ≈ 字段 `10.1743`；人数比 `173/94 = 1.84` 不符 |
| `updateTime` = **日级队列标记**（不随分钟推进） | **实测推断** | 间隔 73s 两次采样业务字段全变而 `updateTime` 恒同值；ARX 与 BTC **完全相同** |
| 均价 `*AvgEntryPrice` 的**加权方式**（简单 / 数量加权） | **官方未公开** ⇒ 只标注 | `avg_entry_price_basis` 写"未公开"，**不推断** |
| 「鲸鱼」= 保证金余额 **Top 20%** | **社区说法，官方未确认** | `whale_definition:"community_claim_unverified"` |
| 「聪明钱」队列成员判定规则 / 鲸鱼门槛 | **官方未公开** | `cohort_definition:"undisclosed"` |
| 上游数据快照时点 | **官方未公开** ⇒ 恒 `null` | `upstream_snapshot_time` |
| 该 bapi 为**网页端内部接口**、无官方文档 | **实测事实** | 若币安改路径/字段需重新取证 |

## 4. 与"旧结论"的关系（诚实说明）

旧模块 `public_market_read.py` 的 `SMART_MONEY_REASON` 写的是
"币安公开 API 无「聪明钱金额/均价/身份」字段"——该结论针对 **`fapi.binance.com` 的公开
REST（`/futures/data/*`、`/fapi/v1/openInterest`）**，**依然成立**。
本次新增的是**另一族端点**：币安**公开页面自身使用的 web bapi**（`www.binance.bh/bapi/...`，
路径含 `/public/`、无鉴权）。两者是**不同来源**，不是对旧结论的推翻。

旧 `smart_money.available:false` 的**保留点**：`public_market_read` / `adapter.v1_public_extras`
的 `smart_money` 字段**本轮未改**（避免与历史侧抢改同一文件）；新数据经**独立**路由
`/api/v1/smart-money/{exchange}/{market_id}` 暴露，与前端既有契约一致。
