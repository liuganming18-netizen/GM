## 二、门禁缺陷整改（逐条对应退回单）

### #1 REST 失败仍退出 0 → 已修

`logs/_pool_restfill.py`（末尾放行契约，原仅 `return 3 if deadline_hit else 0`）：

- 新增 `--exemptions`（**周期绑定**豁免台账）。
- 逐项核算未决：`failed` / `remaining` / `needs_evidence` / `needs_range_evidence` /
  **未解决空段**（`range_empty` 未被有效豁免覆盖）/ **候选不可得**（`rest_empty` 未被豁免）。
- 报告新增 `gate`：`{status: pass|partial|fail, blocking[], partial[], unresolved_empty_ranges[], unresolved_rest_empty[]}`。
- 返回码：`0`=干净；`3`=本轮截止未跑完（partial）；`4`=存在未决阻塞项（fail）。
- 失败**不再**当不可得或成功；按既有调度在允许时点重试。

### #2 覆盖审计无放行作用 → 已修

`历史下载/_audit_pool_coverage.py`（原**无条件 `return 0`**）：

- 改为调用**统一门禁** `logs/_pool_gate.py`（与最终验收**同源判据**，杜绝分叉）。
- 新增 `--tf`、`--gate`；逐周期解析完整验收结果，输出 通过/失败；`--gate` 时未通过**返回 4**。
- `onboard_time` 降级为**仅线索**（`onboard_clue`），不作通过依据。

### #3 最终验收仍可能错误放行 → 已修

`历史下载/_final_acceptance_6tf.py`（原**无条件 `return 0`**；且"库内首根早于 rest_first 即判通过"未核身份）：

- 重写为调用 `logs/_pool_gate.py`，新增 `--tf`、`--gate`（未决 ⇒ 返回 4）。
- **头段**：以官方可得最早边界 `rest_first` 判；库内首根**早于** `rest_first` ⇒
  必须**合约身份已核**（`same_contract`/`different_generation`/`archive_padding`/
  `official_lifecycle_symbol_reuse`）；`unverified` ⇒ **阻塞**。
- **无范围证据** ⇒ 阻塞（不再默认头覆盖）。
- **顺带修正既有缺陷**：原脚本中段洞查询参数顺序错误（`(ex, sym, tf, iv)` 对
  `exchange/market/symbol/timeframe`），导致**内部缺口从未被检出**；已修正为 `(ex, mk, sym, tf, iv)`。

### #4 源不可得证明必须绑定周期与证据 → 已修

- 新增 `logs/pool_exemptions.json`（**周期绑定**豁免台账，27 条）：
  每条含 `exchange/symbol/**timeframe**/准确区间/kind/why` + `evidence{file, sha256}`。
- `_pool_gate.load_exemptions()` **逐条校验证据文件存在且 sha256 相符**；
  证据缺失或哈希不符 ⇒ **视为未豁免（阻塞）**。
- 不再使用无 timeframe 的硬编码 `DOC_ABSENT`；LIT/MAVIA 的 12h 理由**不会**套用到其他周期
  （隔离测试 `test_08_wrong_timeframe_exemption_does_not_cover` 证明）。

### #5 统一截止时点与真实状态 → 已修

- `_work_6tf_chain.py` 在**串联启动时固定一轮截止时点**并持久化到
  `验收证据/PC_round_deadline.json`；该固定时点通过 `--deadline` 传给 REST 补缺
  （不再"各步骤按当时 now 各算"）。
- **完成状态 = 真实全池门禁结果**：每周期末步为 `_final_acceptance_6tf.py --gate`，
  仅当 `exit=0` 才写 `done` 并进入下一周期；退出 0 / 文件生成**不等于**完成。
- 实时采集健康**另列**（不属于本 run）。
