## 2. v3.1 冻结变更（本目录已落地）

1. **半开 UTC 三段**（`segments.py`）：IS `[2022-01-01,2025-01-01)`、
   Val `[2025-01-01,2026-04-15)`、Holdout `[2026-04-15,2026-10-15)`。
   三段**各自 5000U、零仓零挂单**起算；段界重置 cash/orders/positions/execution_state/equity_peak；
   **段末用本段最后 15m 收盘强平**（计不利滑点、费用、应结资金费），**不用下一段开盘**。
   起点前仅指标预热；沿用预热期锚点须一致且不得产生段前开仓。
2. **M2 逐类型超限拒单统计 + 条件 M2b**：`core.m2_over_limit_stats` 按
   spring/breakout/retest 统计 `D_stop>3.5ATR` 计数与比例；分母 = 到达超限判断且具备
   **有效结构 + 执行价**的唯一候选（0 ⇒ N/A 不触发）。任一类型 **IS+Val 合并 > 30%** ⇒
   `core.m2b_trigger` 触发预注册 **M2b**：`D = max(P_entry-(L_struct-0.8ATR), 1.5ATR)`，
   不因 >3.5ATR 拒单，数量按 0.5% 权益/实际距离**自然缩小**。
3. **穿底拒单**：`core.evaluate_entry_fill` 中，使用结构低点的候选若
   `P_entry <= L_struct` ⇒ 拒单原因严格 `entry_below_struct_low`（M2/M2b 均适用）。
   仅用该时刻 open + 已知信号结构 + 滑点/取整，不用同根 15m 未来 low/close。
4. **历史阶梯只跑 M0–M4 + 条件 M2b**；**M5/M6 改前向验证**（`factors.py`）：
   M5 = 全网账户比自身 **30 日**分位 > 90% 过滤；M6 = 大户持仓比自身 **30 日** Z **降序排序**
   （平手保持原序）。每币须前向采集 **≥30 自然日且 ≥90 唯一有效有来源时间快照**才激活；
   未达门槛 M5 不跳过、M6 不改序。已有历史 metrics **不算**前向满 30 天证据。
5. **持仓保护逐 15m**：止损优先，开盘穿 stop 用更差 open + 卖出不利滑点；台阶下一根 15m
   生效且单调上移；720h 到期逐 15m 检查。目标 2R 仅展示。
6. **成本**：M0–M4 及 M2b 全程双边每边手续费 0.05% + 滑点 0.05% + 全部真实结算资金费
   （负费率收入保留）；禁 `norm4h`/`ext1h`/补 0/普通收盘价冒充真实资金费 mark。

## 4. 阶梯定义（只切模式，不改阈值）

- **历史（本轮 IS/Val）**：M0 → M1 → M2 →（条件）**M2b** → M3_BE / M3_Step → M4。
- **前向（Holdout 截止后开始采集）**：M5、M6。
- M2b 与 M2 同一父配置/数据/时间/排序/费用，**只改距离上限**；按原晋级标准比较后再定 M3 父层。

## 5. 使用

```bash
cd 策略
PYTHONPATH=. python -m WyckoffMaster.verify --sha --out <json>
```

四件套：`T1 截断无前视`、`T2 锚点不覆盖与单次确认消费`、`T3 1.5ATR下限/3.5ATR拒单/M2b缩仓/穿底拒单`、
`T4 台阶下根15m生效且不回填`；附加 `T5 ATR口径`、`T6 三段规格`、`T7 执行费用`、
`T8 逐类型超限拒单统计+M2b触发`、`T9 前向门槛`、`T10 配置`、`T11 阶梯`、`T12 Holdout守卫`。
