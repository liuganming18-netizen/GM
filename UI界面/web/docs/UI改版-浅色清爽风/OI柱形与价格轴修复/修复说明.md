# OI 柱形「看不出高低」+ 价格轴被裁 —— 根因与修复

> 触发原话：「oi持仓量柱形显示没有高低波浪怎么能看出来量」
> 结论：**两个独立缺陷叠加**，都已修复并机器验收。

---

## 缺陷 1：OI 柱形齐平（看不出高低）

### 根因

`HistogramSeries` 的柱是从 `base` 画到值，**`base` 默认 0**。

OI 是**绝对存量**而非增量：

| 量 | 数值 |
|---|---|
| `oi_ccy` 全量区间 | 91,594 → 98,791（4.6 天内仅 7.86%） |
| 当前 3 小时可视窗样本 | 11 个，区间 585（**0.64%**） |
| `base = 0` 时柱高占比 | **92.7% ~ 100%** |

柱高差异只有 7.3 个百分点 → 视觉上必然齐平。若切到 `oi_usd`，序列里还有取值为 `0` 的点，会把轴拉到 `[0, 80.2 亿]`，更平。

### 修法（`src/components/LightweightChart.tsx`）

新增按**可视窗自适应基线**，不改数值、不聚合、不重采样：

```ts
/** OI 柱形基线的下缘余量（占可视窗内真实区间的比例）。
 *  0.12 ⇒ 窗内最低柱仍有 12% 柱高、最高柱占满绘图区，高低差一眼可辨。 */
const OI_BASE_MARGIN = 0.12;

const recomputeOiBase = useCallback(() => {
  // 取 chart.timeScale().getVisibleRange() 扫描窗内样本 → min/max
  // base = min − (max − min) × OI_BASE_MARGIN
  // 窗内无样本 → 回落全量；变化 < 0.02% 不下发（抖动抑制）
  safeCall(() => series.applyOptions({ base }));
}, [lifecycle]);
```

接线要点：

- 订阅 `timeScale().subscribeVisibleLogicalRangeChange` → 拖动/缩放实时重算基线；
- 图表实例重建时 `oiBaseRef.current = null`（新实例 base 回到库默认 0，缓存必须作废）；
- 柱数据下发后立即 `recomputeOiBase()`；
- 价格轴刻度**仍是真实总量**（如 92.6k–93.7k），只改柱的绘制基线。

### 效果

柱高由 ~15% 到 100% 明显起伏，绿高红低一目了然。拖动 + 滚轮缩放无异常，无 JS 异常。

## 缺陷 2：右侧价格轴被裁在可视区外

### 根因

| 元素 | 实测 |
|---|---|
| `.market-table-scroll` clientWidth / scrollWidth | **1096 / 1260**（横向溢出 164px） |
| `.workbench-market-table` | `table-layout: fixed`，colgroup 合计 **1260px** |
| 展开行 `<td colSpan={10}>` | 宽 = 整表宽 **1260px** |
| 展开图容器（`w-full h-full`） | 被拉成 **1208px**（x 443–1651） |
| 价格轴画布 | x **1573–1651** |
| 滚动视口右缘 | x **1524** |

→ 78px 的价格轴**整段落在可视区外**，必须横向滚到底才能看到刻度。K 线与 OI 两图都受影响；展开图内右对齐的文案（如「加载更早历史」「1分钟滚动10天…」）同样被裁。

### 修法（`src/components/TokenTable.tsx`）

给展开图包一层「**贴合可视宽 + 吸附左缘**」的壳：

```tsx
/** 横向滚动容器可视宽度，用于把展开图约束在可视区内。 */
const [scrollViewportW, setScrollViewportW] = useState(0);

useEffect(() => {
  const el = scrollRef.current;
  if (!el) return;
  const sync = () => {
    const w = el.clientWidth;
    setScrollViewportW((prev) => (Math.abs(prev - w) > 0.5 ? w : prev));  // 1px 级抖动抑制
  };
  sync();
  const ro = new ResizeObserver(sync);
  ro.observe(el);
  return () => ro.disconnect();
}, []);
```

```tsx
<td colSpan={10} className="p-0 border-b border-neutral-700/80 bg-neutral-950">
  <div className="sticky left-0" style={scrollViewportW > 0 ? { width: scrollViewportW } : undefined}>
    <InlineExpandedChart … />
  </div>
</td>
```

**不改列宽、不改行结构、不动图表内部布局**；`scrollViewportW` 首帧为 0 时退化为 `auto`，与旧行为一致。

### 效果（实测）

| 项 | 修复前 | 修复后 |
|---|---|---|
| 展开图容器宽 | 1208（x 443–1651） | **1044（x 443–1487）** |
| 价格轴画布 x | 1573–1651（**视口外**） | **1409–1487（视口内）** |
| 刻度可见 | 需横向滚到底 | **默认即见** |

K 线刻度：83000.00 / 82800.00 / 82558.50 / 82400.00
OI 刻度：92000.00 / 91892.35 / 91800.00 / 91600.00

## 回归验收

- `npx tsc --noEmit` → **exit 0**
- 四页面不变性探针（`verify.mjs`）→ **全 PASS**（`tagDiffs` / `geoDiffs` 均空）
  - 工作台元素数 2028 → **2029**（+1 = 新增的展开图外壳 div；探针在「有/无 `ai-*` 类」两遍中均含该节点，故不变性判据仍为 0 差异）
- 两图时间轴对齐（像素探针）：竖网格线在**相同 x**（477/557/637/957/1037/1117/1197/1277/1357，间距 80px），OI 的网格线是 K 线的子集（中间 3 条被高柱遮挡导致检测不到）→ 严格对齐
