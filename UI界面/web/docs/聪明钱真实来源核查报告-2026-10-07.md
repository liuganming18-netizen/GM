## 二、原站真实 API 主机与鉴权方式（bundle 源码证据）

**证据点：** `tradeflow_index-27SKEJ8j.js#747823`

```js
async function xT(e,t,n,r){
  let i={method:e,headers:{"Content-Type":`application/json`}};
  (e===`POST`||e===`PUT`)&&n&&(i.body=JSON.stringify(n));
  let a=r?.params?`${t}?${new URLSearchParams(yT(r.params)).toString()}`:t,
      o=await fetch(a,i).then(e=>e.json());
  if(!o.success) throw Error(o.message);
  return o.data
}
```

| 事实 | 含义 |
|---|---|
| `fetch(a, i)` 的 `a` 是**相对路径** | 真实 API 主机 = 前端主机 = `https://www.tradeflow.club` |
| 请求头只有 `Content-Type`，**无 `Authorization`** | 鉴权靠**浏览器同源 cookie 会话**（这正是匿名请求得 401 的原因） |
| GET 参数经 `URLSearchParams` 拼到路径后 | 参数格式为普通 query string |
| 响应信封 `{success, message, data, trace_id/requestId}` | 401 信封里带 `requestId/trace_id/span_id`，证明**是应用自己返回的**，不是网关/反代挡的 |
