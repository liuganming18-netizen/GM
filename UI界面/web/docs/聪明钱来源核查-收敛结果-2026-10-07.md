## 三、是否需权限：需要，且只差这一项

**需要授权的接口（按字段价值排序，全部只读 GET）：**

1. `GET /api/analytics/smart-money-signal/{symbol}/kline?includeTopTraderRatios=true` ← **六槽数据就在这里**（`longPosArr/shortPosArr/longWhalePosArr/shortWhalePosArr/longAvgPriceArr/shortAvgPriceArr` + 三个比率序列）
2. `GET /api/analytics/smart-money-signal/symbols` ← 覆盖币种清单
3. `GET /api/analytics/coin-list` ← 全池六槽快照 + `dataAt`（更新频率）

**只读授权方式（两种，任选其一即可，都不需要交出密钥）：**

- **方式 A（推荐，零密钥）**：用户在**自己的浏览器**保持原站登录（邮箱/密码或 Google 登录），我只在该页面上做**只读观察**（读页面渲染值与网络清单），**不提取、不复制、不输出任何 cookie/token**。
- **方式 B**：由用户提供原站的**只读凭据**（若有该产品提供的 API Key/只读 Token）——**不接受**任何个人交易账户密钥。

**账号要求**：需能访问 `/analytics/smart-money-signal`（菜单标 `User`）与 `/analytics/coin-list`（菜单标 `VIP`）。**具体等级/是否付费 = 未知**（本轮未登录、未付费）。

**拿到会话后能拿到哪几个字段**（可复验）：

- 六槽：多头/空头各自的 `持仓量`、`巨鲸占比`、`持仓均价`（+ 巨鲸均价）
- 摘要卡 9 项：`lastPrice / priceChangePercent / fundingRate / openInterestValue / smartMoneyLongShortRatio / smartMoneyLongOiRatio / smartMoneyShortOiRatio / topPositionRatio / 多空人数`
- 时序 16 条序列 + `updatedAt`（更新频率）+ `symbols` 覆盖币种数
- **拿不到**：队列定义本身（服务端算法，需原站书面说明）
