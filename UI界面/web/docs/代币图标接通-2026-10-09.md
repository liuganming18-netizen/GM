## 回退链（命中即停，按序探测）
1. `https://bin.bnbstatic.com/static/assets/logos/{原始基础资产名}.png`（如 `1000000BOB`）
2. 同上，但用**去倍率前缀名**（`1000000BOB` → `BOB`）
3. `https://assets.coincap.io/assets/icons/{去前缀名小写}@2x.png`
4. 全部失败 → 内置手绘 SVG（6 个主流币）/ 字母占位（其余），**不编造、不用近似图顶替**

## 两个必须记住的实现约束（实测得出）
1. **币安 CDN 挡外链，靠 `Referer` 判定**：
   `无 Referer` → 200；`Referer: http://localhost:3000/` → **403**；`Referer: https://www.binance.com/` → 200。
   ⇒ 所有 `<img>` 必须带 `referrerPolicy="no-referrer"`，浏览器不发 Referer 才取得到图。
2. **币安 CDN 对部分不存在的资产返回 `200` + XML 错误体**（如 `MOG.png` 返回
   `<?xml …><Error><Code>AccessDenied</Code>…`），不是 404。浏览器按「非图片」触发 `onError`，
   回退链据此自然前进，无需额外判定；但**用状态码统计覆盖率会高估**，必须校验 `Content-Type`。

## 性能与缓存
- 模块级 `Map` 缓存「已解析结果」：`string` = 可用 logo URL，`null` = 全部候选失败。
  虚拟列表滚动会反复挂载/卸载同一行，缓存避免重复探测与重复 404。
- `<img>` 带 `loading="lazy"` + `decoding="async"`；容器为固定尺寸圆形容器，
  加载期以内置兜底作底板，避免布局位移；成功加载后隐藏底板（否则透明 PNG 会透出占位字）。
