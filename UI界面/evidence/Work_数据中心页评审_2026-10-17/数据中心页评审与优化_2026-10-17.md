# 数据中心页 · UI 评审与优化（2026-10-17）

> 结论先行：这页的问题不是「信息不够」，而是**「该突出的没突出，该安静的太吵」**。
> 本轮只做「去噪 + 统一」两件事，**没有增删任何一条数据、没有改任何业务逻辑**。

## 一、评审：5 个问题（全部有实测证据）

用真实浏览器（1680×1050）在页面上实测，不是看图说话。

### 问题 1 · 满屏绿 ⇒ 绿色不再是信号

| 实测项 | 数值 |
|---|---|
| 挂绿色徽章的采集卡 | **17 / 17**（每张卡都挂「🟢 正常采集」） |
| 页面内绿色底元素 | **38 处**（其中实心绿底 27 处） |
| 顶部再报一次 | 「正常采集：17 项（绿灯）」 |

绿色在监控语境里代表「**不用管**」。17 张卡全刷绿 + 顶部再报一次，等于把首屏一半面积刷成"无事发生"。
真正的异常（红/黄）反而淹没在里面 —— **信号被稀释成噪音**。

### 问题 2 · 浅色主题里嵌了纯黑块，且块内文字读不清

| 实测项 | 数值 |
|---|---|
| 日志终端底色 | `oklab(0 0 0 / 0.85)` = **纯黑 85%** |
| 终端内「标题」文字色 | `#0b1322`（近黑）→ **深底上深字** |
| 终端内「通道标签」文字色 | `#36445a`（深灰）→ 深底上深字 |
| 标的徽章底色 | `bg-black/60`（又一块黑） |

这是**确凿缺陷**：日志条目的标题「标的停更告警 (>24h未收到结算推送)」在纯黑底上几乎不可见。
根因：`index.css` 只反转了 `neutral-*` / 语义色，**`black` 没被反转**，所以写 `bg-black` 就是真黑。

### 问题 3 · 字号只有一档（还有一档漏网）

| 实测项 | 数值 |

漏掉了第三档 `text-[9px]`**（全项目 21 处，本页渲染 17 处）。这一档实际只有 9px。

## 二、优化方案（已实施）

### ① 常态不刷绿，绿色只留给异常
- 17 张采集卡：去掉绿色徽章 ⇒ 常态只剩**一句安静的灰色「正常」+ 一个中性灰点**；只有异常才升级为红色告警徽章 + 呼吸红点。
- 顶部状态条：绿色/琥珀色胶囊 ⇒ 统一改为**中性文字指标条**；只有 `abnormalCount > 0` 时才出现红色异常项。
- 表格里的「已入库」绿色徽章（13 处）⇒ 中性化。
- 右栏 8 个队列项的绿点 + 绿色增量 ⇒ 中性化。
- 保留绿色：日志级别色（INFO 绿 / WARN 琥珀 / ERROR 红）、数据本身的涨跌语义 —— 这些**是信号**，不动。

### ② 选中态改用品牌蓝（与设计系统一致）
设计系统明确规定：`--ds-accent`（品牌蓝）**只用于主按钮、选中态、焦点环**；`--ds-pos`（绿）只用于数据涨跌。
原实现用绿色表示「当前选中」，语义串台。已改为 `--ds-accent` 蓝。

### ③ 去黑块 + 修可读性
- 日志终端：`bg-black/85` ⇒ `var(--ds-surface-3)`（浅色下沉底）。
- 日志条目：深色底 ⇒ 语义浅底（`--ds-neg-bg` / `--ds-warn-bg` / `--ds-info-bg` / 白）。
- 文字色：原来按「深色主题」配的 `text-*-200/300` ⇒ 改为浅底可读的 `text-*-600`。
- **结果：标题「标的停更告警…」从近黑变深色，在浅底上清晰可读。**

### ④ 补字号层级（根因修复）
`index.css` 的抬底规则补上第三档：
```css
.text-\[9px\], .text-\[10px\], .text-\[11px\] { font-size: 12px; }
```
小字占比 **6.1% → 1.1%**。（残留的 10/11/13px 是设计系统令牌 `--ds-fs-2xs/xs/md` 的既定档位，属正常。）

### ⑤ 统一到设计系统
- 7 张主卡片外壳 ⇒ `.ds-card`。
- 卡片标题 ⇒ `.ds-card__head` / `.ds-card__title`（自带品牌竖条）/ `.ds-card__meta`。
- 状态徽章 ⇒ `.ds-badge` / `.ds-badge--pos|neg|neutral`。
- 顶部指标条 ⇒ `.ds-metrics-inline` / `.ds-mi`。
- 底部「数据完整度与核销标准结论」⇒ `.ds-card` + `<details>` **默认收起**（原为常驻三行长文，占首屏却极少读）。

### ⑥ 修正比例
- 采集卡 `min-h` 92 → 120px，看板 196 → **248px**。
- 富余高度还给日志区（终端 285 → 323px），**页面仍是一屏**（`scrollHeight/clientHeight = 1.00`），不产生空白。
