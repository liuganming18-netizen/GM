## 回测页改了什么

1. **页头常驻**：标题 + 视图切换 + 6 个区块导航（点击平滑跳转，滚动自动高亮当前区块）。
2. **当前结果工具条**（sticky）：随时看到「现在在看哪一次 run」及其净收益 / 回撤 / 笔数。
   旧版要滚到页面最底部的「实验记录」才知道选中的是哪个 run。
3. **指标卡重做**：数字限长（旧的 `1.29048909413528` 会把卡片撑变形）；主指标加左侧色条；
   缺失一律中性色，不再用颜色冒充方向。
4. **表格统一**：sticky 表头、数字右对齐、选中行改用左侧色条（旧版整行变色会淹没盈亏色）、
   空态写明「为什么空」。
5. **提示条统一**：四种语义（信息 / 通过 / 失败 / 告警），结论加粗 + 依据等宽。
6. 顺手修掉 3 处 Markdown 星号字面残留（`**仅含当前策略**` 之类）。

## 第二轮：精简（渐进披露）

用户反馈「太杂了，不要显示过多的数字跟说明」。原则是 **默认只留决策必需的，其余收进折叠区 / 次要列**，
**功能与 DOM 一个不少**（验收脚本仍能查到全部字段），只是默认不占视野。

| 位置 | 改法 |
|---|---|
| ① 运行配置 | 默认只留「交易对 + 窗口起止 + 运行回测」；交易所 / 市场 / 周期 / 预热 / 成本 / 风险与策略参数收进「高级设置」 |
| ② 收益指标 | 8 张卡 → **4 张主卡**（净收益率 / 最大回撤 / 胜率 / 交易次数）+ **1 行紧凑指标条**（平均盈亏比 / Profit Factor / 手续费 / 资金费）；口径与夏普基准折叠。表头的 run_id / 执行 / 质量徽标删除（顶部工具条已常驻） |
| 结果身份 | 12 项 KV → **4 项** + 两个折叠（其余身份字段 / 审计明细） |
| ③ 资金分析 | 「口径与一致性核对」「月度明细与完整性核对」改为折叠；异常（基准缺失 / 缺时点）仍默认可见 |
| ⑤ 逐笔明细 | 13 列 → **默认 7 列**（进场时间 / 标的 / 方向 / 开仓价 / 出场价 / 净盈亏 / 退出原因），其余列由「更多列」展开 |
| ⑤b 订单明细 | 整卡折叠 + 11 列 → **默认 6 列** |
| ⑤c 拒单明细 | 整卡折叠（4 列不变） |
| ⑤d 资金费结算 | 整卡折叠 + 6 列 → **默认 4 列** |
| ⑥ 实验记录 | 10 列 → **默认 7 列**；质量报告改为「结论 + 异常项徽标」+ 折叠全部核对项 / 现金恒等式对账 / 代码 hash / 输入快照；M4 门禁 JSON 与边界声明折叠 |
| 全页 | 卡片标题去掉括号里的长解释（如「⑤ 逐笔明细（点击任意行 ⇒ 图表定位该 trade_id + 显示单笔详情）」→「⑤ 逐笔明细」，点击提示改为原生 tooltip） |

实现机制：
- 次要列 = `<th|td data-secondary>`，CSS `.ds-table [data-secondary]{display:none}`；
  点「更多列」给表加 `.ds-table--all` 才显示。**列一直在 DOM 里**。
- 折叠卡 = 原生 `<details class="ds-card">` + `<summary class="ds-card__head">`；
  因页面有 5s 轮询，`open` **不交给 React 受控**，只在挂载时用 `useEffect` 设一次初值。
- 折叠区内的「更多列」按钮会 `preventDefault + stopPropagation`，避免连带开合卡片。

runs     10 → 7   shown: run_id 状态 创建时间（UTC） 净收益 回撤 笔数 失败原因
默认折叠：lab-orders / lab-rejected / lab-funding / lab-quality-details / lab-quality-hashes
        / lab-run-identity-more / lab-run-audit / lab-audit-details / lab-m4-gate / lab-runs-hashnote

## 第三轮：一屏（「一眼全部能看」）

用户反馈「还是太繁杂了。一眼全部能看的效果」。第二轮做的是「折叠」，第三轮反过来了：
**不是折叠，是重排成单屏仪表盘** —— 一屏之内把关键信息全部铺开，次要面板改为「按需展开」。

实测：页面总高 **3231px → 995px**，滚动比 **3.36 → 1.00**（1680×1050 视口，**完全不需要滚动**）。

| 改法 | 说明 |
|---|---|
| **页头去导航** | 一屏看完就不需要区块跳转 ⇒ 删掉 6 项区块导航与 scroll spy，页头从两行 89px 压到一行 56px |
| **① 运行配置 → 单行** | 原来是两张卡、两行输入。现在 `.ds-bar` 一行放完：`运行配置 | 交易对 | 起点 → 终点 | 运行回测 | 高级设置 刷新`（70px） |
| **② 收益指标 → 单行** | 原来是 4 张大卡 + 1 行紧凑条 + 折叠口径。现在 **8 个指标全部挤在一行**（36px），口径移到底部审计面板 |
| **③ + ⑤ 左右并排** | 净值曲线（7/12）与逐笔明细（5/12）同屏并排，而不是上下堆叠 |
| **④ 执行视图 / 结果身份 / 订单 / 拒单 / 资金费 / 口径与审计** | 移入一行「更多视图」按钮组（单选展开）。**默认 0 高度，点开就是完整内容，一个字段不删** |
| **⑥ 实验记录** | 去掉「表格 + 质量面板」两列网格（质量面板移入审计面板），表格限高，整卡变矮 |
| **退出原因** | 后端英文原值（`intrabar_stop`）在窄列里会被截断成 `intrabar…` ⇒ 映射为等义中文短标签（盘中止损 / 收盘强平 / …），`title` 始终带原值，**未知值原样显示** |
| 新增样式 | `.ds-dash` 12 列栅格 + `.ds-col-7/6/5`、`.ds-bar`（单行工具条）、`.ds-tablewrap--tight/mid/tall`（表内滚动限高）、`.ds-panelbar`（按需展开按钮组）、`.ds-mi__v--pos/neg/muted` |

关键取舍：**「一屏」不等于「删功能」**。执行视图 / 订单 / 拒单 / 资金费 / 质量明细 / hash / M4 门禁
全部还在，只是从「常驻视野」变成「一行按钮，点开即见」。

实测（Chromium 1680×1050，选第一条 run）：

```

各区块高：配置 70 · 指标 36 · ③+⑤ 并排 347 · ⑥ 327 · 更多视图 44
默认可见列：trades 7/13 · runs 7/10（与第二轮一致）
「更多视图」6 个按钮默认 aria-pressed=false
```

截图见 `回测页_单屏/`（初始态 / 一屏总览 / 展开执行视图 / 展开审计 / 展开订单 / 验收复盘回归）。

## 第四轮：K 线图置顶常驻

用户反馈「把回测执行 k 线图移到上面来」。第三轮把 ④ 执行视图塞进了「更多视图」按钮组
（默认 0 高度），代价是**每次看 K 线都要点一次**。本轮把它提出来做成**常驻**，并放到页面上部。

| 改法 | 说明 |
|---|---|
| **④ 执行视图 → 常驻并上移** | 从「更多视图」按钮组里删除，改为与 ③ 资金分析**左右并排**，紧跟在 ② 收益指标之后（col-7 / col-5）。「更多视图」由 6 项变 5 项（结果身份 / 订单 / 拒单 / 资金费 / 口径与审计） |
| **页面顺序** | ① 运行配置 → ② 收益指标 → 更多视图按钮组 → **④ 执行视图 + ③ 资金分析** → ⑤ 逐笔明细 + ⑥ 实验记录 → 按需面板 |

## 第五轮：去重与等高（「太繁杂、比例不对」）

用户反馈「这个 UI 页面太繁杂了。比例也不对。简洁一点」。本轮解决两件事：**顶部横条太多且重复**、
**同排卡片不等高**。

### 一、顶部 4 条 → 2 条

| 改法 | 说明 |
|---|---|
| **删掉「收益指标」独立横条** | 它和「当前结果」条**重复显示**净收益 / 回撤 / 笔数（同一个 run）。现并入同一条：4 个主指标常显 + 「▸ 更多指标」展开 4 个次要指标（平均盈亏比 / Profit Factor / 手续费 / 资金费） |
| **删掉「更多视图」独立横条** | 5 个面板按钮并入「当前结果」条（放指标条件分支**之外**，任何状态都在）。新增 `.ds-toolbar--dense`（8px 间距）避免 17 个条目换行 |
| **「当前结果」条常驻** | 原来只在选中 run 时渲染；现在未选时显示「未选择运行 · 在下方『实验记录』点一行…」的引导，不再需要单独的「收益指标」空态卡 |

### 二、同排卡片自动等高

原来靠逐张调像素对齐，一旦某张卡的内容行数变化就又错位。改为**栅格层解决**：

```css
.ds-dash { align-items: stretch; }            /* 原来是 start */
.ds-dash > * { display: flex; flex-direction: column; min-width: 0; }
.ds-dash > * > * { flex: 1 1 auto; min-height: 0; }
```

矮的那张被拉伸到与高的一致 ⇒ 卡片外框对齐，**下方不再出现「一张高一张矮」的缺口**。
实测两行都精确等高：`414 / 414` 与 `385 / 385`。

### 三、顺手去掉的视觉噪声

| 位置 | 改法 |
|---|---|
| ④ 执行视图头部 | 2 行 → **1 行**：删掉描述性徽标「K 线 / 成交量 / 信号 / 开平仓 / 保护止损」（说明移入标题 `title`）、`672 根（真实）`→`672 根`、`滚轮缩放 · 拖动平移` 移入 `title` |
| ③ 资金分析曲线 | 两条线的末值标签会**压住右侧价格轴刻度数字**（末值接近时更明显）⇒ 基准线 `lastValueVisible: false` + `title: ''`，只留策略线一个标签。两条线的识别交给下方读数条（已有同色标记 + 末值） |
| ⑥ 实验记录底部 | 整段黄色「边界声明」→ 一行折叠条（`lab-m4-disclaimer`），全文一键展开，信息不删 |
| 空间再分配 | 省下的高度还给图：K 线容器 `215 → 273`（画布 `750×186 → 750×244`，宽高比从 4.0 改善到 3.1）、净值曲线 `140 → 195`、两张表限高 `240/208 → 276/236` |

## 第六轮：规范页同步（新原语回填）

第五轮改在 `components.css` 的 **4 个新原语**（`.ds-toolbar--dense`、`.ds-dash` 等高、`.ds-bar`、
`.ds-panelbar` / 表格限高），当时只落进代码、**没进规范页**。规范页的铁律是
「新令牌 / 新组件**必须先加进规范页**再在页面使用」，所以本轮补上，把两张皮合成一张。

### 一、新增第 16 节「栅格与等高」

插在「页面结构」组最前（`#grid`），其后各节序号整体 +1：页头 16→17、区块导航 17→18、
图表配色 18→19、使用准则 19→20、令牌索引 20→21（现共 **21 节**）。

内容：
- **12 列栅格**说明：`.ds-col-7` / `.ds-col-5` 并排、`.ds-col-6` 对分、`<1200px` 退化整行（**只改排布、不隐藏内容**）。
- **等高演示**：左卡（`ds-col-7`，含图表占位）与右卡（`ds-col-5`，内容少）。
- 规格表：`.ds-bar` / `.ds-panelbar` / `.ds-tablewrap--tight|--mid|--tall` 的用途与约束。
- 一条 warn 提示：**限高 ≠ 隐藏**（表内滚动的行仍在 DOM，`data-secondary` 列也不得从 DOM 移除）。

### 二、`.ds-toolbar--dense` 加进第 17 节「页头与工具条」

同一组条目并排渲染 **默认 gap 12px** 与 **dense gap 8px** 两条，并附 info 提示：
17 个条目 × 12px 间距 ≈ 多出 190px，会把「口径与审计」挤到第二行、条高 42 → 78px。

> **踩坑（本轮）**：demo 起初按规范页正文宽度（约 750px）渲染，dense 条**自己也换行了** ——
> 反而否定了它要证明的事。真实页面可用宽 1400px 才放得下 17 个条目。
> 修法：给 demo 内层 `min-width: 1400px` + 外层 `overflow-x: auto`，按真实视口宽度渲染。

| 新增行 | 类名 |

| 栅格 | `.ds-dash` `.ds-col-7` `.ds-col-6` `.ds-col-5`（同排自动等高） |
| 单行条 | `.ds-bar` `.ds-bar__label` `.ds-bar__sep` `.ds-panelbar` `.ds-panelbar__label` |
| 行内指标 | `.ds-mi` `.ds-mi__k` `.ds-mi__v` + `--pos|--neg|--muted` |
| 表格限高 | `.ds-tablewrap--tight` `--mid` `--tall` |

「工具条」行补 `+ --dense`。
